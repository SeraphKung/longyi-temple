# 龍懿慈惠堂｜六十甲子籤

以繁體中文製作的手機優先靜態網站，提供線上抽籤、三次擲筊模擬、六十首籤詩查閱、解說及分享。

## 使用方式

直接以靜態檔案託管 `index.html`、`qian-data.js` 與 `assets/` 即可，不需安裝套件、建置工具、伺服器或環境變數。網站不收集姓名、生辰或問事內容；抽籤與擲筊只在訪客瀏覽器本機隨機模擬。
